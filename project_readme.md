# NEO-TACTICS // Quantum Grid

Welcome to **Neo-Tactics: Quantum Grid**, a feature-rich, ultra-modern, and fully playable arcade **Tic-Tac-Toe** game built from scratch using pure HTML5, CSS3 (Tailwind CSS), and Vanilla JavaScript.

---

## 🚀 Features & Highlights

- **Stunning Cyberpunk UI/UX:** Built with a sleek dark-mode glassmorphism design, ambient glowing orbs, neon cyan/magenta styling, and fully responsive layout.
- **Two Game Modes:**
  - **Player vs Player (PvP):** Enjoy classic local multiplayer with a friend on the same device.
  - **Player vs AI Bot:** Test your tactical skills against an intelligent neural bot featuring **Standard** and **Quantum / Impossible (Minimax Algorithm)** difficulty levels.
- **Web Audio API Sound Synthesizer:** Fully immersive custom sound effects generated natively in the browser—no external audio files needed!
- **Confetti Celebrations:** Celebratory particle animations triggered whenever a player achieves victory.
- **Live Score Tracking:** Automatically tracks wins for Player X, Player O/AI, and Draws across rounds.
- **Zero External Framework Dependencies:** Lightning-fast client-side execution.

## 🎮 How to Run and Play Locally

1. **Clone or Download** this repository to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/VOSC-Activity-1.git
   ```
2. Open the project folder in your favorite code editor (such as **VS Code**).
3. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari), or use the **Live Server** extension in VS Code.
4. Have fun playing!
